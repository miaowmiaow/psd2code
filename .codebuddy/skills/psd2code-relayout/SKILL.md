# psd2code 区块重建（截图驱动）

## 核心前提

PSD 的图层摆放不遵守前端规范，因此**原产物的 DOM 结构不能作为布局依据**。产物只提供两样东西：

1. **图形素材**——每格长什么样（直接截渲染结果，不做 CSS 坐标推算）；
2. **验收基准**——重建后与原渲染比对。

新结构由「截图上是几行几列、列宽多少、间距多少」决定，类名按前端规范重新命名。

## 重建一个区块的完整流程

### Step 1 · 在截图上找到区块的边界

用 `scan_page.py` 生成全页切片，逐张看图，确定：

- 区块在哪几行（每行是一个「行容器」）；
- 每行几列；
- 哪些格与其它格不同构（比如宝箱列比标准格矮）。

产物的职责到此为止——只需找到「行容器」的 class，用来取坐标。

### Step 2 · 跑重建脚本

```bash
python scripts/rebuild_block.py <html_dir> \
    --rows section-bg-3,section-bg-7,section-bg-4,section-bg-5,section-bg-6 \
    --name prop-wall \
    --compare
```

脚本做的事：

1. 浏览器实测每格坐标（**不是**解析 CSS 累加，flex 容器里会算错）；
2. 隐藏文字后按格截图 → 每格一张 PNG（图形天然零误差）；
3. 读每格的 `span` 文本、字号、颜色、相对偏移；
4. 生成 `<section class="prop-wall"><div class="prop-wall__cell"><img>…<span>`；
5. 用 grid 排布，轨道宽/高把「间距」并进去（间距不等也能精确复现）；
6. 替换原行，清理死规则，输出 `index_ai.html` / `style_ai.css`。

### Step 3 · 验收

`--compare` 会打印重建区域的差异：

```json
{"div_before": 521, "div_after": 330,
 "css_rules_before": 464, "css_rules_after": 272,
 "diff_ratio": 0.00413, "max_delta": 190}
```

判定标准（**不是零差异**）：

| 指标 | 期望 |
|---|---|
| `diff_ratio` | ≤ 0.6%（残差几乎全部来自文字抗锯齿） |
| `max_delta` | 可以较大（个别字形边缘），但差异必须集中在文字行 |
| 结构 | 每格 = 1 `img` + N `span`，层级数不再随原产物变化 |

差异集中在**图形轮廓**说明位置算错了，去看 `track_w` / 每格的 `margin-top`；差异集中在**文字区**才是正常残差。

### Step 4 · 视觉复核

看图确认：格子间距、行列对齐、宝箱列的错位是否与设计稿一致。数字对得上但视觉不对，通常是有格子的 `dy` 没补（矮格在行内居中）。

## 实测收益（南瓜大作战 · 道具墙 5×4）

| 指标 | 原产物 | 重建后 |
|---|---:|---:|
| `div` 总数 | 521 | **330**（−191） |
| CSS 规则 | 464 | **272**（−192） |
| 单格层级 | 12 层 | **2 层** |
| 区域差异 | — | **0.41%** |

单格结构从「prop ▸ prop-icon ▸ prop-bg ▸ rounded ▸ img ＋ prop-bg-2-x ▸ rounded-N ▸ btn ＋ group ▸ rect/text/candy」变成「cell ▸ img ＋ span」。

## 硬约束

1. **文字永远是 DOM 文本**，截图时用 `visibility: hidden` 隐藏（不能用 `display: none`，会改变布局）。
2. 坐标一律浏览器实测；CSS 累加在 flex 容器内会错。
3. 图形一旦截图就不可编辑——只对「需要还原度、不需要改内容」的装饰区块用这个办法。
4. 只处理规则网格。行列不等距可以，但必须是「行 × 列」形态；自由拼贴区块不适用。
5. 原产物不动，输出并列文件。

## 反模式

- 解析 CSS 的 `left/top` 累加算坐标（flex 容器里父子的定位方式不同，必然算错）。
- 用 `column-gap` 表达不等间距（会累加误差，第 3 列起就偏 1px）。
- 把文字也截进图片（失去可维护性，且改文案就得重新出图）。
- 追求零像素差（重建结构后字形渲染必然有残差，应看差异分布而不是总量）。
